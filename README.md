# Java Programming Exercises

This repository contains standalone Java programming exercises. The code is structured to be simple, neat, and highly professional, utilizing basic Object-Oriented principles. No complex frameworks or enterprise architectures are enforced.

## Exercises

### 1. JSON Parser / Validator (`JSONP`)
Manually parses and validates basic JSON input from standard input and counts the total elements within it, without using external JSON libraries.

### 2. XML Parser / Validator (`XMLP`)
Manually parses and validates basic XML tags and values from standard input, ensuring tags match correctly, without using external XML libraries.

## Getting Started

### Prerequisites
You need the Java Development Kit (JDK) installed to compile and run these exercises.

### Compile
You can compile all exercises using the standard `javac` command from the root of the repository:
```bash
javac src/*.java
```

### Run
To run an exercise, execute the main class with the `java` command, ensuring you include the `src` directory in the classpath:

**Run JSONP:**
```bash
java -cp src JSONP
```

**Run XMLP:**
```bash
java -cp src XMLP
```
